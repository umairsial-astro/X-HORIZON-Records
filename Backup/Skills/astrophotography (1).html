13 — FORMULA REFERENCE

Working Equations

FOV (deg) ≈ 57.3 × sensor dimension (mm) / focal length (mm)

Sensor dimension and focal length in the same units; result is an approximation valid for small angles.

Image scale ("/px) = 206.265 × pixel size (µm) / focal length (mm)

206.265 converts the small-angle radian ratio to arcseconds.

f/# = focal length / aperture

Both in the same length unit (mm).

Total integration = exposure per sub × number of subs
SNR ∝ √N

N = number of stacked independent sub-exposures, assuming similar noise characteristics per sub.
