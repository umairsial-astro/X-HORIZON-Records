Why FITS matters

The Flexible Image Transport System is the format astronomy standardized on decades ago, and most archive downloads still arrive this way.

  • Header — plain-text keyword/value metadata: instrument, target, exposure time, coordinate system, units.
  • HDUs — a file can hold several Header/Data Units: an image, then a table, then another image.
  • Tables — binary or ASCII extensions storing catalogs, spectra, or time-series alongside the image.
  • Units — every value's physical unit lives in the header; never assume, always read it.

Uncertainty & error

  • Random error scatters results; systematic error shifts them consistently.
  • Precision is repeatability; accuracy is closeness to the true value.
  • Uncertainty propagates — combined quantities carry combined error.
  • A result without an error bar is not yet a scientific result.
σ_f² ≈ (∂f/∂x)²σ_x² + (∂f/∂y)²σ_y²

Units & coordinates

  • Astronomical unit, parsec, light-year, solar mass, solar radius — know which one a paper is using.
  • Flux and wavelength units differ by instrument; convert before comparing datasets.
  • Right Ascension / Declination (celestial), Galactic coordinates, Cartesian state vectors — pick the frame the question needs.
