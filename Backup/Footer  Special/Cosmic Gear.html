EVA Tool Workflow

Useful sequence astronauts follow so tools stay controlled, tasks stay safe, and ground teams can verify every step.

1. Configure

Set torque, battery, socket, camera, lighting, restraint position, and tether path before leaving the airlock.

2. Translate

Move along handrails with primary and secondary tethers while keeping tool bags and cables clear of snag points.

3. Stabilize

Use foot restraints, body restraint tethers, or robotic positioning so both hands can work without drifting.

4. Execute

Complete the hardware task with torque checks, connector verification, fastener capture, and video confirmation.

5. Inspect

Use helmet cameras, external cameras, lights, and ground callouts to verify blankets, cables, seals, and latches.

6. Stow

Return every tool to its restraint point, confirm no loose objects, and close the worksite before airlock ingress.
